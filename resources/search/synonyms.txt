# Search synonyms: one group of equivalent words per line, comma separated.
#
# Mix any languages and scripts: English, French, Arabic, Tunisian derja in Latin letters.
# Include the English word when products are named in English, so "sabbat" finds "Sneakers".
# Spelling doesn't need to be exact: accents, case, أ/ا, ى/ي, ة/ه and the Arabic "ال"
# are normalized away ("Soirée" = "soiree", "الأحذية" = "احذيه").
# Multi-word entries are fine ("huile d'olive").
#
# Avoid very common words that mean something else in another language
# (French "or" = gold but also "or", French "the" = tea), and words that also name
# another product ("basket" = sneakers in Tunisia, but also "Woven Storage Basket").
#
# A group can be limited to some categories (slugs) with "@" at the end of the line:
#   set, ensemble, tenue  @ fashion-clothing, sports-outdoors
# Then "ensemble" finds clothing sets, never a "Ceramic Plate Set" or a "Headset".
# Exact words always rank above synonyms; a synonym only widens the results.
#
# Changes apply on the next search (the file is re-read when it changes).
# Queries that find nothing are listed in the admin panel (Search > Missed queries):
# that's the best source of new lines for this file.
